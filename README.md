# 🚀 Taing SiveMinh (TSMDev) — Premium Developer Portfolio

A modern, high-end, responsive personal portfolio website engineered with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, **Lucide React**, and **Khmer (ភាសាខ្មែរ) / English bilingual support**.

---

## 🌟 Features

- ⚡ **Minimal, Futuristic Dark Theme**: Clean `#08090d` aesthetic with subtle grid pattern, interactive mouse spotlight, and soft glowing accents.
- 🌐 **Full Bilingual Support (EN / KH)**: Instant toggle between English and Khmer (using Google's *Kantumruy Pro* font) with `localStorage` persistence.
- 📱 **Mobile-First & Responsive**: Fluid glassmorphic navigation with mobile drawer and active scroll spy.
- 💼 **Showcase & Deep-Dive Modals**: Filterable projects (*All, SaaS, Full Stack, Frontend*) with case study modals detailing Problem, Solution, Key Features, Tech Stack, Challenges & Results.
- 🛠️ **Interactive Skills Matrix**: Categorized technical repertoire (*Frontend, Backend, Database, Cloud & DevOps*) with live hover glow.
- 🧭 **Journey Timeline (2023 - 2026)**: Visual milestone roadmap documenting growth as a Full-Stack Engineer.
- 📬 **Contact & Toast Feedback**: One-click copy for Telegram/Email/GitHub/LinkedIn and interactive contact form with confetti celebration.
- 🔍 **SEO & Performance**: OpenGraph tags, Twitter Card meta, `robots.txt`, `sitemap.xml`, and SVG favicon.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Animations**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React
- **Typography**: Inter, Kantumruy Pro, JetBrains Mono

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/taingsiveminh/Portfolio-.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
